# Asset sources

- SharpGrotesk-Medium20.otf: user-supplied font, copied from the specified local font file.
- InterVariable.woff2: https://github.com/rsms/inter, SIL Open Font License 1.1.
- icons/*.svg: Microsoft Fluent UI System Icons 1.1.341, MIT license, https://github.com/microsoft/fluentui-system-icons. Selected through the Fluent Icons plugin.
- nigeria.json: geometry from the user's existing ONSA project. Used as an illustrative reference pending geographic source verification.

- Geist TTF files: Geist font family; see `fonts/Geist-LICENSE.txt` (SIL Open Font License).
- DM Mono: see `fonts/DMMono-LICENSE.txt` (SIL Open Font License).
- `figma-overview/` and `figma-table/`: assets exported from the supplied HSRY Products Align Figma file. Source frames and asset mappings are recorded in `docs/figma-overview-assets.json` and `docs/figma-table-assets.json`.
- `nigeria-region.json`: illustrative regional map geometry used by the overview; geographic provenance remains to be verified before production use.

The supplied Sharp Grotesk font and Figma design assets are not covered by the open font or icon licenses listed above. Their presence in this project does not grant redistribution rights.
